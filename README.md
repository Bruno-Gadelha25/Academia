# 🏋️ Academia

Site moderno e responsivo desenvolvido para uma academia, com design clean, cores neutras e foco em conversão. Estruturado com seções de planos, benefícios, depoimentos e contato, conta com integração ao WhatsApp para facilitar o atendimento. Projeto otimizado para mobile, com navegação simples e visual profissional.

🔗 **Ver online:** https://academia-red-mu.vercel.app

## ✨ Destaques

- Layout **responsivo**, pensado primeiro para o celular
- Contato direto pelo **WhatsApp**, para converter visitante em cliente
- Animações suaves com **Motion** e ícones **Lucide**
- Página única, leve e com carregamento rápido via **Vite**

## 🛠️ Tecnologias

| Camada | Ferramenta |
|---|---|
| Interface | React + TypeScript |
| Estilo | Tailwind CSS |
| Animações | Motion |
| Build | Vite |
| Deploy | Vercel |

## ▶️ Como rodar localmente

```bash
git clone https://github.com/Bruno-Gadelha25/Academia.git
cd "Academia/academia"
npm install
npm run dev
```

Acesse **http://localhost:3000**.
